## What changed
1. **Planner (`planner.mjs`).** One added rule, `VISIBLE_STATE_RULE` (after `UTTERANCE_RULE`), and one key in the output shape: `"visible_trace": false` on every axis. A visible physical trace is declared as an axis with `visible_trace: true`; every non-opening option names the body part, garment or object and completes "with ..."; no emotion word, no bare word, no negation; `end_state` names each trace that holds at the last frame. `coerceAxis` keeps the flag. `planStateIssues` joins the speech/sequence checks (third attempt allowed, no new budget). Plans without the flag carry nothing, so stored E4.7 plans replay byte for byte.
2. **`state.mjs` (new).** `visibleOptionIssue` (emotion lexicon, negation, slug, fewer than 2 content words, and with the entity: must name what it is on); `foldState` (state at the START of clip N = opening + changes of clips 1..N-1; a clip's `end_state` is the authority on its last frame: where it names >= 60% of another option and < 50% of the folded one, that option wins; silence changes nothing, no decay; conflicts listed); `withCarriedState` (subject line `..., now with X; <job>.`, retention `partially_preserved - identity and <unchanged things> from its reference picture; X from the previous clip`, else untouched object); `citeRetention`; `stateFacts`; `carriedInSubjectLines`; `stateContradictions` (a sentence about the subject stating another option, not also affirming the carried one); `stateReport`.
3. **Wiring.** `film.mjs` folds once per film (`state_fold.json`) and applies it to each refPack; `clip.mjs makeShot` carries `state` only when there is one; `writer.mjs e4Facts` appends the state facts; `hybrid46/validate.mjs` adds the `state_contradiction` finding (repaired by the normal targeted repair); `checks.mjs planContinuity` reports `state_end_disagree`; `report.mjs` adds a `state` section; `pictures.mjs` lets a retention line cite its own subject's `<Picture N>`; `export-prompts.mjs` cites it.
4. **Tooling.** `closure.mjs` derives the runtime file list from the code (static and absolute imports, data files named by modules, including `templater/*.mjs` and `templater/taxonomy/*.json`); `freeze.mjs` hashes it; `trace-reads.mjs` + a test check a real replay reads nothing outside it. `replay-check.mjs --stored-plan`; `replay-state.mjs`.
5. **Tests.** `test/e48.test.mjs`, `test/cases48.mjs` (>= 5 positive and 5 negative per rule). `test/e47.test.mjs` lost its file-identity and replay tests (they stay in `planpath47/test`); `antioverfit.test.mjs` allowlist gained generic body/garment/emotion words and the new CLI files.

# E4.11 FROZEN

E4.11 is E4.10 (`planpath410/`, tag `e4.10-frozen`) built for FEW REPAIR PHASES and for PARALLEL requests. `planpath410/` and older directories are untouched; E4.11 is the copy `planpath411/`. Verify: `node planpath411/verify-frozen.mjs` (exit 1 if a listed file changed); git tag `e4.11-frozen`. Output contracts are those of E4.10 (planStory, makeBible, runStory, the report shapes; fields were only added), so the extender's bridge can vendor it with the same patches (plus one: `postfix.mjs` and `fixes.mjs` import only repository files). Generic rules only (DON'T-CHEAT: `antioverfit.test.mjs` polices it; E4.11 was built and tested on invented tables, not on any test story).

## What changed
1. **Plan fixes before any retry (`fixes.mjs`).** Camera term spelling; state_changes that cite the ledger loosely (matched, added to a trace axis, or dropped with a record); option grammar (subject strip, axis noun prefix, emotion-word unit drop); opening value added when missing; progressive axis moving backwards stays put (warning); a missing aftermath axis added from the aftermath vocabulary at the clip and shot of the cue; the end_state rewritten from the folded ledger (the ledger is the authority); shot seconds redistributed inside the clip for the 2.2 words/s ceiling.
2. **HARD / SOFT (`planner.mjs`).** HARD = shot count, seconds sum, missing end_state, identical raw asks, speech described without a line, sequence continuity, unparseable. Everything else is SOFT = a recorded warning. At most TWO planner calls; only hard issues go back; the plan with fewer hard issues is kept (first on a tie). Prompt gains a positive LEDGER BOOKKEEPING rule.
3. **Bible (`biblefix.mjs`, `bible.mjs`).** Language, side, speaker map filled by code; base wording and opening-state wording stripped in code; at most two calls, hard issues only; opening-state and base-wording findings are warnings. Prompt asks voicePrompt to state age, register and pace in plain words.
4. **Clip writer (`postfix.mjs`, `writer.mjs`, `hybrid46/pipeline.mjs`).** Prevention: a "currently:" line per carried subject next to the subject definitions, the speaker form with the voice phrase, the blocking and eyeline sentence, the description word floor. Code post-fixes: speaker id, vocal identity, blocking, eyeline, camera term, negation substitution, contradicting clause removal. Only render-breaking findings reach the repair call; negation, narration, label, blocking, eyeline, too-short and vocal-identity findings are warnings.
5. **Concurrency.** `E4_CONCURRENCY` (default 6, max 8): one limiter for every request (`lib.mjs`), staging chain first. `planparallel.mjs`: skeleton call then all parts at once (stories over 14 clips; `E4_PLAN_MODE=skeleton|single|auto`). `decide.mjs`: per clip a parallel half (references, camera movement, tactic, effort, habit) and the staging chain. `film.mjs`: a clip is written when its decisions are in; results by clip index; per-clip resume.
6. **Report (`report.mjs`).** `e411` section: repair-call rate per stage, calls by stage, retries, fixes by kind, warnings, tokens, wall time.

The first Swift 1.5 pilot on three new stories (`results/2026-10-13-e4.11/run1`, now dev data) left clip repair at 38-62 per cent of clips. Three definitional changes, then new stories (set B) for every claim:
1. `state_contradiction` reaches the repair call only when the sentence states at least two and at least three quarters of the other option's distinctive words (`strongContradiction`); a one-word coincidence of vocabulary ("open", "dry") is a warning. `state.mjs` reports `hits` and `distinct` on the finding.
2. A line the writer split over two consecutive `<d>` tags is merged when together they spell the ledger line exactly (`dialogue_tags_merged`); a speech-verb finding whose span lies inside the dialogue line's own words is a warning.
3. Reference-image prompts (`refs.mjs`): a prompt whose only issues are filler/glow words or a short object list is a warning, not a repair call.
